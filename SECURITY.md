# Security policy

## Supported versions

Security fixes are made against the latest tagged release and the `main`
branch. Older releases may not receive a backport.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include
credentials, account data, or exploitable details in a pull request.

Use
[GitHub private vulnerability reporting](https://github.com/oliver-mee/hermes-alibaba-token-plan/security/advisories/new)
to send the affected version, impact, reproduction steps, and any suggested
mitigation privately. Remove or redact credentials and personal data.

You should receive an acknowledgement within seven days. The maintainer will
coordinate validation, remediation, disclosure, and credit with the reporter.

For ordinary setup problems, catalogue drift, or non-sensitive bugs, use the
[public issue chooser](https://github.com/oliver-mee/hermes-alibaba-token-plan/issues/new/choose).
